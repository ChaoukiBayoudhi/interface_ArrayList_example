# Interface Array List example

A Java console application.

## Tech stack

- Java (no build tool: plain source files)

## Concepts covered

Stream API, collections, console input (Scanner), exception handling, interfaces, lambda expressions.

## Project structure

- `Entities`: Car, Icar
- `Enumerations`: CarConstructor
- `Traitement`: Main
- `implementation`: ListCars, TableCars

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).
